Responsive & layout notes

Phone (this view), ≤600px: single column, bottom tab bar for Student/Teacher primary nav, full-width cards, sticky CTA buttons at screen bottom for payment / submit actions.

Tablet, 600–1024px: bottom tabs become a persistent left icon-rail (72px). Two-column content where natural — e.g. Marketplace shows a master list (activities) with a detail pane beside it instead of full navigation; Content Builder shows the module tree on the left and the selected lesson's editor on the right.

Desktop, >1024px: left rail expands to a labelled sidebar (like this jump rail). Dashboards move to a 12-column grid: KPI tiles in a row, then a two-thirds/one-third split for primary list + side summary (e.g. Admin Overview: approval queue + platform wallet). Forms such as Create Course use a two-column layout with a sticky live-preview summary card on the right instead of stacking.

Accessibility

  • All buttons, tabs, chips and list rows keep a minimum 44×44px hit target (36px "mini" icon controls are paired with generous spacing and are never the only way to complete a required action).
  • Text contrast: body text uses Ink #0F1A24 on light surfaces (>13:1). Where Talent Cyan #00ADEF, Talent Orange #F5901A or Marketplace Blue sit behind text, we set dark Ink text on top (≥7:1) rather than white. Talent Red is used at a deepened shade (#C81E27) with white text for buttons so red CTAs still clear 4.5:1 — the brighter #ED1C24 is reserved for badges, borders and large headings.
  • Status is never color-only: paid/behind/unpaid, verified/pending/suspended and quiz right/wrong states all pair a color with a label or icon.
  • Focusable fields show a visible outline; reduced-motion is respected for the payment stepper (it still advances, without extra easing).

About this prototype

All data shown (teachers, students, transactions) is representative demo content. "Downloads" and file uploads are simulated with realistic timing — no real files move. Payment numbers (Paybill, account, receipts) are illustrative and not connected to a live M-PESA account.
